Install INOVEX Tasks

Use the Task Manager as an app on your phone or computer.

The app is installed. Look for “INOVEX Tasks” on your home screen or apps list. Open without installing

iPhone / iPad Your device

  1. Open this page in Safari.
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen, then Add.

Android Your device

  1. Open this page in Chrome.
  2. Tap Install the app above, or the ⋮ menu → Install app.
  3. Tap Install.

Windows Your device

  1. Open this page in Chrome or Edge.
  2. Click Install the app above, or the install icon at the right of the address bar.
  3. It appears in the Start menu; right-click to pin it to the taskbar.

Mac Your device

  1. Chrome / Edge: click Install the app above, or the install icon in the address bar.
  2. Safari (macOS Sonoma or later): File → Add to Dock.
  3. Open it from the Dock or Launchpad.

Linux / ChromeOS Your device

  1. Open this page in Chrome, Edge or Chromium.
  2. Click Install the app above, or the install icon in the address bar.
  3. It appears in your applications menu.

The app updates itself. Sign in the same way as on the website: your INOVEX Google account, or the email code if an administrator invited you without an INOVEX email. Help: info@inovex-group.com or h.musaimi@inovex-group.com.
