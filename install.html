Add INOVEX Tasks to your iPhone

iPhone has no install button: you add the app from Safari's Share menu. It takes 4 taps.

Different screen? Steps for other iPhone versions

iOS 26 and later: ⋯ → Share → Add to Home Screen → Add. iOS 18 and earlier: Share button (square with arrow, bottom bar on iPhone, top bar on iPad) → Add to Home Screen → Add. Chrome / Edge on iPhone: Share button in the address bar → Add to Home Screen. Needs iOS 16.4 or later for Chrome/Edge; Safari works on all versions.

First start: open the new icon, choose INOVEX staff (or Invited), and sign in once with your INOVEX Google account. The app keeps you signed in. If signing in keeps coming back, delete the icon and add it again with Open as Web App turned off: it then opens in Safari with Safari's sign-in.

iPhone / iPad Your device

  1. Open this page in Safari (not inside WhatsApp, Gmail or another app).
  2. iOS 26 or later: tap ⋯ next to the address bar → Share. Older iOS: tap the Share button (square with an arrow).
  3. Scroll down, tap Add to Home Screen, keep Open as Web App on, then tap Add.

Android Your device

  1. Open this page in Chrome.
  2. Tap Install the app above, or the ⋮ menu → Install app.
  3. Tap Install.

Windows Your device

  1. Open this page in Chrome or Edge.
  2. Click Install the app above, or the install icon at the right of the address bar.
  3. It appears in the Start menu; right-click to pin it to the taskbar.

Mac Your device

  1. Chrome / Edge: click Install the app above, or the install icon in the address bar.
  2. Safari (macOS Sonoma or later): File → Add to Dock.
  3. Open it from the Dock or Launchpad.

Linux / ChromeOS Your device

  1. Open this page in Chrome, Edge or Chromium.
  2. Click Install the app above, or the install icon in the address bar.
  3. It appears in your applications menu.

If signing in does not work

  • Update the app first: close it completely and open it again (it updates itself on the next start).
  • Sign-in keeps coming back: make sure you chose INOVEX staff when the app first opened (or tap Change sign-in type). On the portal, use Sign in with my INOVEX Google account; if it still returns, tap Add my INOVEX account and sign in once.
  • Android: the app uses Chrome's sign-in. Open Chrome, sign in at google.com with your INOVEX account, then open the app.
  • Invited without an INOVEX email: choose Sign in with an email code and use the exact address the administrator added.
  • Installed before 31/10/2026: uninstall the old app and install it again from this page.

The app updates itself. Sign in the same way as on the website: your INOVEX Google account, or the email code if an administrator invited you without an INOVEX email. Help: info@inovex-group.com or h.musaimi@inovex-group.com.
